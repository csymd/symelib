# GROBID Integration Plan

## Overview
GROBID is a machine learning tool for extracting structured information from scholarly PDFs (title, abstract, authors, references, etc.).

We'll add optional GROBID support to PDFProcessor for better metadata extraction.

## Steps
1. Add GROBID client/service.
2. Make it optional (local Docker or API).
3. Integrate into processing pipeline.
4. Update schema for richer metadata.
